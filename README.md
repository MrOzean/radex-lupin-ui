# Lupin Light Lab

Неофициальный современный веб-интерфейс для люксметра-пульсметра-яркомера **RADEX LUPIN** — полнофункциональная замена настольного RadexLight. Всё работает локально в браузере: живое измерение через Web Serial, осциллограмма и спектр, коэффициент пульсации по ГОСТ, запись и эталоны из оригинальных `.bpulse`/`.pulse`.

## Быстрый старт

1. **Подключите LUPIN** к USB (Chrome или Edge, страница по HTTPS или `localhost`).
2. Нажмите **«Подключить»** — поток осциллограммы пойдёт сам, показания появятся через секунду.
3. При первом запуске введите калибровку прибора: запустите утилиту коэффициентов (см. ниже) — она напечатает два числа; введите их в поля «Корректирующий множитель» и «Пересчёт яркости» (значения по умолчанию 1.0 и 3.4 подходят для большинства приборов).
4. Переключайте **лк / кд/м²**, фильтр, диапазон спектра — всё применяется мгновенно.
5. **«Начать запись»** сохраняет полный поток; **«Эталон из .bpulse/.pulse»** накладывает оригинальный файл RadexLight поверх графиков для прямого сравнения.
6. Без прибора — кнопка **«Демо-источник»** включает виртуальный сигнал.

Подробный отчёт с доказательствами и границами знаний: [docs/research/radexlight-protocol.ru.md](docs/research/radexlight-protocol.ru.md). Форматы файлов: [docs/file-format.ru.md](docs/file-format.ru.md). Текущее состояние: [docs/project-status.ru.md](docs/project-status.ru.md).

## Возможности

- **Живое измерение** — USB CDC 921600 8N1, пакеты `OSCILLOSCOPE` (6000 отсчётов/с), Web Serial API.
- **Метрология, подтверждённая против оригинала** — парсер пакетов бит-в-бит (±3×10⁻⁶), пересчёт яркости через заводской `lumDiv` (кд/м² = лк / 3.4), коэффициент пульсации по ГОСТ `(max−min)/(2·среднее)`, спектр до 3000 Гц, доминирующие частоты.
- **Калибровка** — корректирующий множитель и делитель яркости сохраняются между сессиями.
- **Запись и архивы** — полный поток в `.lupinlab` с повторной обработкой; чтение оригинальных `.bpulse`/`.pulse` RadexLight как эталона поверх графиков.
- **Нормативные оценки** — профили помещений и работ, цветовые зоны по освещённости и пульсации.
- **PWA** — устанавливается, работает офлайн, демо-источник для проверки без прибора.

## Запуск

```powershell
npm install
npm run dev
```

Сборка и тесты:

```powershell
npm run build
npm test
npm run preview
```

Для подключения нужен Chrome/Edge. Web Serial недоступен в Firefox/Safari; на iOS потребуется другой транспорт.

## Утилита коэффициентов

LUPIN не передаёт калибровку по UART — заводские коэффициенты (делитель яркости `lumDiv`, множитель) зашиты в USB-серийный номер, недоступный браузеру. Утилита на Go читает их напрямую (Windows/macOS/Linux):

```powershell
go build -C tools/lupin-coeffs -o lupin-coeffs.exe .
.\tools\lupin-coeffs\lupin-coeffs.exe
# вывод: lumDiv 3.4, multiplier 1 — введите в поля приложения
```

Готовые бинарники под все платформы — в релизах.

## Публикация и релизы

- **GitHub Pages**: push в `master` автоматически собирает и публикует приложение (`.github/workflows/pages.yml`; в настройках репозитория включите Pages → Source: GitHub Actions).
- **Релизы**: тег `v*` запускает `.github/workflows/release.yml` и прикрепляет к Release веб-архив для статического хостинга, бинарники `lupin-coeffs` (win/mac/linux), архив исходников и `sha256sums.txt`.

## Технологии

- **Angular 22.2**, standalone-компоненты, signals и zoneless change detection;
- **ECharts 6** — легенда, tooltip, масштабирование, pan, экспорт PNG/SVG;
- Web Serial API, TypeScript 6, RxJS.

## Структура

- `src/app/services/measurement.service.ts` — состояние измерения, пауза, статистика, FFT и запись;
- `src/app/services/serial.service.ts` — Web Serial, пакеты LUPIN и ограниченный журнал;
- `src/app/services/demo.service.ts` — виртуальный источник;
- `src/app/components/chart-panel.component.ts` — жизненный цикл и управление ECharts;
- `src/app/components/terminal-dialog.component.ts` — диагностический HEX-терминал;
- `src/lib/lupin.ts` — инкрементальный разбор пакетов `OSCILLOSCOPE`;
- `src/lib/analysis.ts` — статистика, коэффициент пульсации, FFT, доминирующие частоты;
- `src/lib/bpulse.ts` — чтение оригинальных файлов `.bpulse`/`.pulse`;
- `tools/lupin-coeffs/` — утилита чтения заводской калибровки (Go);
- `research/` — инструменты read-only анализа официального ПО;
- `docs/research/` — результаты исследования.
