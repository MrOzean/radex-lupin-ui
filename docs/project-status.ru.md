# Lupin Light Lab — итог рабочего дня

Дата: 2026-11-09 · обновлено 2026-11-12

## Текущий итог

Создано работающее кроссплатформенное веб-приложение для RADEX LUPIN. Основной путь проверен на реальном приборе:

```text
LUPIN → USB CDC COM5 → Web Serial → OSCILLOSCOPE packets →
6000 float32 LE → статистика → фильтр → осциллограмма/FFT → UI/CSV
```

По основному пользовательскому сценарию — подключение и живой анализ света — повторена большая часть полезного функционала RadexLight. Это уже не прототип с случайными числами: правильность подтверждена изменением освещённости и спектра от реальных источников.

## Что работает и проверено

### Подключение и протокол

- USB VID `ABBA`, PID `E011`, стандартный `usbser`;
- Web Serial, 921600 бод, 8N1, DTR/RTS;
- маркер `OSCILLOSCOPE`;
- 6000 float32 little-endian на пакет, 24 012 байт с маркером;
- инкрементальный парсер с частичными чтениями и ресинхронизацией;
- отбраковка отрицательных, NaN/Infinity и значений выше спецификационных 200 000;
- тесты на реальном захвате, включая битый пакет и последующее восстановление.

### Измерения

- текущая освещённость/яркость;
- минимум, максимум, среднее;
- коэффициент пульсации;
- полный спектр 0…3000 Гц с шагом 1 Гц;
- нормировка по сумме модулей FFT без принудительного пика 0 дБ;
- локальные доминирующие частоты выше −40 дБ;
- переключаемый НЧ-фильтр 500 Гц;
- корректирующий множитель;
- переключение лк / кд/м²;
- пауза/продолжение без закрытия COM-порта.

Проверки на источниках:

- лампа: около 147 лк, пульсация 1.2–1.8%, пик 100 Гц;
- закрытый датчик: около 0.6 лк;
- фонарик: около 480 лк, пик 400 Гц.

### Интерфейс

- Angular 22.2, standalone components, signals, zoneless change detection;
- ECharts 6;
- легенда, tooltip, перекрестие;
- масштабирование колесом, pan и slider;
- сброс масштаба без потери обновлений потока;
- линия/столбцы/свечи для спектра;
- разворачивание графика на видимую область, закрытие по Esc;
- экспорт графиков PNG/SVG;
- диагностический HEX-терминал с ограничением истории;
- адаптивная раскладка;
- запись сводных значений и экспорт CSV.

### Стабильность

Soak-тест около 20 минут: без зависаний, память вкладки около 15 МБ, периодическая нормальная работа GC. Первичная проблема производительности из-за неограниченного HEX-журнала устранена.

### Сохранение и загрузка (2026-11-12)

- полный необработанный поток сохраняется в `.lupinlab`: JSON-заголовок + float32 LE;
- в файл входят время, частота, единицы, коррекция, фильтр, комментарий, источник и метаданные прибора;
- сохранённые файлы открываются без прибора, включая повторную обработку исходного сигнала;
- есть временная шкала, шаг по окнам, выбор длительности окна, абсолютное время на графике, zoom/pan и экспорт PNG/SVG;
- выбранное окно архива экспортируется в CSV с индексом, абсолютной меткой и точным относительным временем каждого отсчёта;
- round-trip формата и обработка повреждённых файлов покрыты автотестами (`npm test`);
- компоненты Angular разделены на отдельные TS/HTML/CSS-файлы.

## Что осталось

### 1. Совместимость и экспорт архивов

- оценить и при возможности добавить чтение `.pulse`/`.bpulse`;
- для очень длительных записей рассмотреть потоковую запись в файл через File System Access API вместо накопления в памяти.

### 2. UI/UX-полировка

- привести заголовки и растущее число кнопок к компактному виду;
- вынести редкие действия в меню;
- улучшить мобильную раскладку;
- показать состояния ожидания пакета, потери синхронизации и отброшенных пакетов;
- сделать индикаторы комфортности динамическими;
- настройки диапазона спектра, цветов и серий;
- доступность: focus states, клавиатура, контраст, aria-labels;
- проверить экспорт SVG при свечах и сильном zoom.

### 3. Метрологическая сверка

- сравнить числовые результаты с RadexLight на одном источнике;
- отделить арифметическую и интегральную пульсацию;
- проверить оконную функцию и фильтр оригинала;
- текущий FIR визуально совместим, но не доказан бит-в-бит;
- проверить калибровку и поведение яркости;
- восстановить коэффициент преобразования освещённости в яркость (`lumDiv`) из прошивки/калибровки прибора или скриптов RadexLight; при невозможности — подобрать по контрольному измерению;
- после этого сделать настоящий числовой пересчёт лк ↔ кд/м²; текущий переключатель меняет только единицы отображения.

### 4. Жизненный цикл прибора

- сделать удобное восстановление после полного закрытия порта;
- исследовать состояние после останова, при котором ранее требовался USB-reset;
- получить тип, серийный номер и firmware;
- обработать отключение USB во время работы.

### 5. Поставка

- production HTTPS;
- PWA/офлайн;
- lazy-loading/разбиение Angular + ECharts bundle;
- инструкция по Chrome/Edge и Android OTG;
- расширенные тесты и длительный soak-тест после новых функций.

## Архитектура

- `MeasurementService` — поток, статистика, FFT, фильтр, пауза, единицы и запись;
- `SerialService` — Web Serial, пакеты и журнал;
- `DemoService` — виртуальный источник;
- `ChartPanelComponent` — ECharts, режимы, zoom, экспорт, expand;
- `TerminalDialogComponent` — диагностика;
- `src/lib/` — протокол, DSP, запись и низкоуровневый transport.
