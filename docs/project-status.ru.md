# Lupin Light Lab — итог рабочего дня

## Итог 2026-11-17

### Реверс (прибор подключён, хуки Frida)

- Идентификатор устройства в оригинале — **не по UART**: парсится из USB-серийной строки (символ `lupinInstPathToSerial`). Формат: серийный номер u32 + дата выпуска + код страны + два float'а калибровки.
- **`lumDiv = 3.4`** и множитель по умолчанию `1.0` прочитаны из серийника прибора; переключатель лк/кд в оригинале чисто программный (0 записей в COM-порт), формула: **кд/м² = лк / lumDiv** (подтверждено: 15 лк ↔ 4,5 кд/м²).
- Инструменты: `research/radex_stats_hook.js` (хук геттеров `EsEapData` + диспетчера свойств скриптового движка), `research/capture_stats.py`, отчёт в `docs/research/radexlight-protocol.ru.md` §12.

### Приложение

- Настоящий числовой пересчёт **лк ↔ кд/м²** через делитель яркости (поле «Пересчёт яркости», сброс ÷3.4); корректирующий множитель и делитель сохраняются в localStorage.
- `lumDiv` пишется в заголовок `.lupinlab` (опциональное поле, старые файлы читаются).
- Сброс скользящего буфера осциллограммы при смене единиц/коэффициентов — без рывков на графике.

### Утилита коэффициентов

- `tools/lupin-coeffs/` — автономная программа на Go (stdlib only), читает серийник прибора и печатает калибровку: Windows (CIM), macOS (system_profiler/ioreg), Linux (/sys). Сборки: `go build`, кросс-компиляция win/mac/linux. Браузер не имеет доступа к USB serial — связь с приложением ручная, один раз.

### Проверки

- `npm test`: 22 теста; production-сборка успешна; дерево чистое (9 коммитов за сессию).

## Текущий итог

Создано работающее кроссплатформенное веб-приложение для RADEX LUPIN. Основной путь проверен на реальном приборе:

```text
LUPIN → USB CDC COM5 → Web Serial → OSCILLOSCOPE packets →
6000 float32 LE → статистика → фильтр → осциллограмма/FFT → UI/CSV
```

По основному пользовательскому сценарию — подключение и живой анализ света — повторена большая часть полезного функционала RadexLight. Это уже не прототип с случайными числами: правильность подтверждена изменением освещённости и спектра от реальных источников.

### Надёжность на приборе

- Горячее отключение USB подтверждено: сразу появляется постоянное предупреждение, данные записи сохраняются.
- Закрытие порта теперь снимает DTR, как RadexLight; повторный цикл подключения проверен на приборе.
- Выбранный SerialPort повторно используется без лишнего системного диалога.

### Реверс

- Для известного unpacked `.bpulse` извлекаются 6000 float32, статистика и метаданные. Текущий прибор: `DeviceType 60002`, `order 1592`, firmware `1.3`, дата `2017-05-15`.
- Восстановлен 12-байтовый кадр Ekosfera, контрольные суммы заголовка/payload, маркеры `7B/7A`, ответ `RPC + 0x8000` и основные RPC ID.
- Добавлены безопасный кодек и диагностический ping. На живом приборе ping получил тайм-аут на 921600 и 9600, адреса `FF` и `0`: RPC в текущем пользовательском режиме не подтверждён. Это не мешает потоку `OSCILLOSCOPE`.
- Расширенный захват RadexLight показал 3487 чтений и 0 записей: обычный live-режим не использует RPC.

## Что работает и проверено

### Подключение и протокол

- USB VID `ABBA`, PID `E011`, стандартный `usbser`;
- Web Serial, 921600 бод, 8N1, DTR/RTS;
- маркер `OSCILLOSCOPE`;
- 6000 float32 little-endian на пакет, 24 012 байт с маркером;
- инкрементальный парсер с частичными чтениями и ресинхронизацией;
- отбраковка отрицательных, NaN/Infinity и значений выше спецификационных 200 000;
- тесты на реальном захвате, включая битый пакет и последующее восстановление.

### Измерения

- текущая освещённость/яркость;
- минимум, максимум, среднее;
- коэффициент пульсации;
- полный спектр 0…3000 Гц с шагом 1 Гц;
- нормировка по сумме модулей FFT без принудительного пика 0 дБ;
- локальные доминирующие частоты выше −40 дБ;
- переключаемый НЧ-фильтр 500 Гц;
- корректирующий множитель;
- переключение лк / кд/м²;
- пауза/продолжение без закрытия COM-порта.

Проверки на источниках:

- лампа: около 147 лк, пульсация 1.2–1.8%, пик 100 Гц;
- закрытый датчик: около 0.6 лк;
- фонарик: около 480 лк, пик 400 Гц.

### Интерфейс

- Angular 22.2, standalone components, signals, zoneless change detection;
- ECharts 6;
- легенда, tooltip, перекрестие;
- масштабирование колесом, pan и slider;
- сброс масштаба без потери обновлений потока;
- линия/столбцы/свечи для спектра;
- разворачивание графика на видимую область, закрытие по Esc;
- экспорт графиков PNG/SVG;
- диагностический HEX-терминал с ограничением истории;
- адаптивная раскладка;
- запись сводных значений и экспорт CSV.

### Стабильность

Soak-тест около 20 минут: без зависаний, память вкладки около 15 МБ, периодическая нормальная работа GC. Первичная проблема производительности из-за неограниченного HEX-журнала устранена.

Добавлена и подтверждена на реальном приборе обработка неожиданного отключения USB: сброс состояния порта, остановка измерения без потери уже записанных данных, постоянное уведомление и повторное подключение. Сценарии обрыва и ручного закрытия покрыты автотестами.

### Сохранение и загрузка (2026-11-12)

- полный необработанный поток сохраняется в `.lupinlab`: JSON-заголовок + float32 LE;
- в файл входят время, частота, единицы, коррекция, фильтр, комментарий, источник и метаданные прибора;
- сохранённые файлы открываются без прибора, включая повторную обработку исходного сигнала;
- есть временная шкала, шаг по окнам, выбор длительности окна, абсолютное время на графике, zoom/pan и экспорт PNG/SVG;
- выбранное окно архива экспортируется в CSV с индексом, абсолютной меткой и точным относительным временем каждого отсчёта;
- round-trip формата и обработка повреждённых файлов покрыты автотестами (`npm test`);
- компоненты Angular разделены на отдельные TS/HTML/CSS-файлы;
- динамические шкалы освещённости и пульсации с профилями помещений/работ, статусы ожидания/пропадания потока и счётчики пакетов, ресинхронизаций и отброшенных байт.
